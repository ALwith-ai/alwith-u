# 浏览器连接：02 与 03 的区别

## 02 开关关闭

扩展已安装，但“启用浏览器控制”开关关闭，连接桥尚未注册，当前尚未连接。

产品提示：打开“启用浏览器控制”以注册桥。

## 03 开关打开

扩展已安装，“启用浏览器控制”开关打开，连接桥已注册，但当前连接尚未建立。

产品提示：重新加载扩展或重启浏览器，再次检测。

## 如何区分

两种状态的圆点都是一绿一灰：第一个表示扩展已安装，第二个表示连接尚未建立。区分它们要看开关状态和提示文字。

右侧是浏览器缩略卡片和连接详情浮层。浮层锚定在卡片右下角的状态圆点，向左展开；示例保留真实产品组件的错开和重叠位置。
