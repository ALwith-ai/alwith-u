# 浮窗聊天：只展示窗口差异

## 新建会话

首次打开浮窗时，侧栏的“打开聊天浮窗”、全局快捷键（默认 Option/Alt + Space）和双击桌宠都可进入新聊天草稿。浮窗已有内容时，这些入口会唤回已有内容，不会再创建新会话。

在已有浮窗对话的更多操作中选择“新聊天”，或选择“新建项目”并选取文件夹，可以开始新聊天；也可以从浮窗顶部的项目菜单新建项目内聊天。

## 打开已有会话

- 主窗聊天的“更多操作”中选择“移到浮窗”，将当前会话和草稿交接到浮窗。
- 在活动列表点击带浮窗标记的会话，在浮窗中打开该会话。
- 在浮窗顶部的项目菜单中选择已有聊天，在浮窗中切换会话。
- 浮窗已有会话或草稿时，也可通过侧栏入口、全局快捷键、双击桌宠唤回；这些共用入口在“会话入口”中各保留一个示例。
- 右侧隐藏屏显示聊天浮窗卡片时，点击卡片打开窗口。

## 整体样式

新建聊天、已有对话各保留一个示例，用于查看真实浮窗的标题栏、输入区和聊天区域。已有对话仅放简短文本，不再重复展示各种消息格式。

## 窗口操作

两个菜单示例均通过真实“更多操作”按钮展开。新建时提供新建项目与回到聊天主窗；已有会话时还提供新建聊天。菜单里其余共用操作保留组件原样，不再逐项重复制作示例。

点击“回到聊天主窗”会把当前会话、目录和输入草稿交回主窗，并隐藏浮窗。主窗移入浮窗、浮窗返回主窗的连续操作，保留在“流程 → 浮窗聊天 → 聊天窗口切换”中。

关闭窗口或按 Escape 可隐藏浮窗并保留草稿。

## 连接提醒

浮窗已经打开后，连接断开、连接失败或选中的会话暂时不存在时，顶部显示源码中的重连提示条。这是浮窗外层自己的界面；主窗草稿的连接提醒使用不同组件，所以保留一例。

## 收起为桌宠

顶部“收起”按钮是浮窗独有入口。没有桌宠时提示前往抽取，已有但未装扮时提示前往装配。两个示例直接展开真实弹窗。已装扮并成功收起时，浮窗隐藏，桌面显示桌宠；示例展示真实桌宠窗口的内容。

## 共用内容统一去主窗聊天查看

主窗和浮窗都使用 ChatView → ConversationView，新建时都使用 DraftChat。内容类型、思考、计划、工具执行、生成过程、权限请求、问题、表单、外部服务授权，以及历史、只读、停止、模型错误，都只保留在主窗聊天目录；从浮窗目录移除重复示例并不代表浮窗不支持这些能力。
