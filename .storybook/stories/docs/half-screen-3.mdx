# 右侧隐藏屏：桌宠休息区的显示逻辑

未登录或桌宠宿主尚未初始化完成时，不渲染桌宠休息区。

未装扮桌宠且未开启时显示空巢选择入口，点击进入桌宠中心。已装扮且未开启时，桌宠显示在休息区；单击桌宠不打开桌面窗口，拖出休息区才触发放到桌面。

桌宠已开启时，休息区保留背景，不重复绘制同一桌宠。

应用卡片、工具窗口卡片和桌宠休息区可以同时出现。休息区固定在下方，卡片区域在上方滚动。示例保留真实组件的布局与背景。
