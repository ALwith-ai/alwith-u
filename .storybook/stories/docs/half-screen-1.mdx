# 应用卡片：不显示与显示

## 01 不显示应用卡片

没有正在运行的默认浏览器或飞书类应用时，不渲染应用卡片。未安装、未运行的应用不会出现在这里。下方桌宠休息区仍按自己的条件显示。

## 02 显示应用卡片

默认浏览器、飞书/Lark/Feishu 正在运行时，显示对应卡片。本示例同时展示 Chrome 和飞书：Chrome 的扩展已安装、浏览器控制已启用且连接已建立，右下角显示两盏绿灯；飞书保持真实的普通应用卡片样式，没有这套连接指示灯。

卡片是否出现取决于应用是否运行，Chrome 的连接状态只影响圆点和连接详情，不会决定卡片是否出现。示例复用真实组件；没有应用图标时使用组件自带的缺省图标。
