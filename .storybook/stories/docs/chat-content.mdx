# 聊天内容的分组逻辑

## 内容类型

内容类型分为用户发送和 AI 回复。用户发送示例展示文字和图片附件；直接添加附件仅支持图片。AI 回复示例包括文字排版、表格、代码、公式、图表、链接、文件资源和图片。示例使用真实聊天组件与隔离数据。

HTML 源码在聊天里显示为代码块，不在聊天消息中运行网页。网页链接和本地文件链接走不同的真实打开逻辑。Markdown 是消息的排版方式，本地 MD 链接则是文件入口。

## 执行状态

分为“执行进程”和“当前活动”。执行进程展示等待首次响应、计划、输出、用户补充指令、上下文压缩和回复结束；当前活动展示思考及工具活动的运行提示，以及展开后的详情。一次真实执行可以多次交替思考、调用工具和输出，压缩也不固定发生在某个步骤。

## 需要用户处理

操作授权、异步问题、表单补充、外部服务连接授权分别对应实际支持的交互组件。

## 文件变更、历史与异常

文件修改展示工具产生的变更与差异。历史与访问包含恢复中、多轮历史、长会话和只读状态。停止与异常区分首次回复前停止生成、会话断开后重新连接和模型错误。这些均保留当前产品组件的呈现方式，不修改产品逻辑。
