## Default Permission

Allows the embedded decoration frontend to activate, update measured geometry, and invoke its closed window-control API.

#### This default permission set includes the following:

- `allow-frontend-ack`
- `allow-frontend-document-boot`
- `allow-frontend-document-ready`
- `allow-frontend-geometry`
- `allow-window-control`
